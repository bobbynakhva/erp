# Payments (`frmPayments`) Specification

## 1. Overview
- **Menu Route:** Cash Flow → Payments
- **Menu Click:** `mnuPayments_Click`
- **Internal VB6 Form:** `frmPayments`
- **Primary Database Tables:** `fund_trans`, `bank_trans`, `bank`, `vendor`, `supplier`, `staff`, `expense`, `purchase`, `dcsubconincoming`, `misc`

## 2. Visual Layout & UI Controls

### Top-Left: Payment Running No. (`Frame4`)
- **Payment No (`lblPayId` / `txtPaymentNo`):** Auto-increment voucher ID (`P_R_A`), searchable and navigatable.
- **Payment Dt. (`DTPPayDate`):** Payment date picker (defaults to system date).

### Top-Right: Cash & Bank Balance Details (`Frame5` / `msfCash`)
- FlexGrid table with 3 columns:
  - `Bank Name`
  - `Balance`
  - `Credit Limit`
- Lists:
  - `Cash Balance`: calculated from `Misc.openbal` + cash receipts - cash payments.
  - Active Banks: calculated from `bank_op_bal` + bank receipts/deposits - withdrawals (`DrawAmt`).

### Middle-Left: Select Bank Or Cash Type (`Frame3`)
- Radio options:
  - `Bank` (`optBank`): Enables nested Bank Details.
  - `Cash` (`optCash`): Disables Bank Details.
- **Bank Details (`frameBank`):**
  - `Our Bank Ac` (`cmbBank`): Dropdown of active bank accounts.
  - `*Cheque No` (`txtChNo`): Cheque number string.
  - `*Cheque Date` (`DTPCHDate`): Cheque date picker.

### Bottom-Left: Payments Details (`frame`)
- **Expense Type (`txtExpType` / combo):**
  - `Purchase` (Vendor)
  - `SubContract` (Supplier)
  - `Salary` (Staff)
  - `General Expense` (Direct / Indirect Expense heads)
- **Pay To (`txtToWhom`):** Searchable autocomplete or dropdown of payees based on Expense Type:
  - If `Purchase`: Active Vendors from `vendor` table
  - If `SubContract`: Active Subcontractors from `supplier` table
  - If `Salary`: Active Employees from `staff` table
  - If `General Expense`: Active Expense accounts from `expense` table
- **Payment Type (`txtPayType`):**
  - `Against Bill`: Displays unpaid / open invoices in the bills grid.
  - `On Account`: Applies payment against overall ledger / opening balance.
  - `Advance`: Records an advance payment tracked in `AdvAmount` / `AdvBalance`.
- **Amount (`txtAmount`):** Numeric amount paid.
- **Amount in Words (`lblWords`):** Live automatic English words conversion.
- **\* Description (`txtDesc`):** Narrative remarks for the payment voucher.

### Middle-Right: Unpaid Bills Grid (`msflexBills`)
- Visible when `Against Bill` is selected:
  - Columns: `Select` | `Bill / Inv No` | `Bill Date` | `Bill Amount` | `Pending Balance` | `Amount to Pay`
- Selecting one or more bills automatically distributes or populates the payment amount.
- Displays Party Balance & Advance Balance badge (`msfBal` / `lblBal`).

### Bottom Toolbar (`Frame2`)
- Buttons:
  - `New`: Clears form, loads next voucher number, selects Bank by default.
  - `Save`: Validates and commits voucher, updating `fund_trans`, `bank_trans`, and bill balances.
  - `Modify`: Modifies existing voucher if no downstream reconciliations lock it.
  - `Delete`: Deletes voucher, safely restoring invoice balances and reversing cash/bank entries.
  - Navigation: `|<<` (First), `<<` (Previous), `>>` (Next), `>>|` (Last).
  - `Cheque Leaf Print`: Opens cheque printing layout.
  - `Printer`: Prints standard payment voucher / receipt.
  - `Close`: Closes window.

## 3. Database Schema

### `fund_trans`
```sql
CREATE TABLE IF NOT EXISTS fund_trans (
  id integer GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  factory_id integer NOT NULL REFERENCES factories(id),
  year_label text NOT NULL,
  fund_trans_id integer NOT NULL,
  p_r_a integer NOT NULL,
  dates timestamp with time zone NOT NULL,
  datet date NOT NULL,
  is_expense boolean NOT NULL DEFAULT true,
  p_r_a_type text, -- 'Against Bill', 'On Account', 'Advance'
  p_r_a_src_dst text, -- 'Cash' or 'Bank'
  exp_inc_id integer,
  party_name text,
  amount double precision NOT NULL DEFAULT 0,
  amt_bal double precision NOT NULL DEFAULT 0,
  adv_amount double precision NOT NULL DEFAULT 0,
  adv_balance double precision NOT NULL DEFAULT 0,
  bank_id integer,
  bank_name text,
  ch_no text,
  ch_date date,
  description text,
  track_bill text, -- Linked Bill/Invoice No(s)
  status_c boolean NOT NULL DEFAULT true
);
```

### `bank_trans`
```sql
CREATE TABLE IF NOT EXISTS bank_trans (
  id integer GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  factory_id integer NOT NULL REFERENCES factories(id),
  year_label text NOT NULL,
  trans_id integer NOT NULL,
  dates timestamp with time zone NOT NULL,
  datet date NOT NULL,
  bank_id integer NOT NULL,
  draw_amt double precision NOT NULL DEFAULT 0, -- Payments
  dept_amt double precision NOT NULL DEFAULT 0, -- Receipts / Deposits
  ch_no text,
  ch_date date,
  descr text,
  fund_trans_id integer,
  p_r_a integer,
  is_hidden_trans integer DEFAULT 0,
  status_c boolean NOT NULL DEFAULT true
);
```

## 4. Business Logic & Validations (from VB6 bytecodes)
1. **Payee Validation:** Pay To / Whom must be specified and match a valid party in the chosen Expense Type.
2. **Amount Validation:** Amount must be numeric and greater than 0.
3. **Cheque Details Validation:** If Bank payment is selected, Bank account must be chosen and Cheque No cannot be blank.
4. **Bill Settlement Logic:**
   - If `Against Bill`, the amount allocated to each invoice cannot exceed its pending `Balance`.
   - On Save: `Balance = Balance - AmountPaid`. If `Balance` reaches 0, the invoice is fully settled.
   - On Delete: Reverts invoice balance: `Balance = Balance + AmountPaid`.
5. **Cash & Bank Balances:**
   - Real-time recalculation of cash in hand and each bank account balance.
