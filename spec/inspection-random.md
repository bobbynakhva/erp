# Specification: Final Inspection Report - Random Samples (`frmInspection`)

## 1. Overview
The **Final Inspection Report (Random Samples)** module (`frmInspection`) provides quality assurance and dimensional measurement logging for manufactured and labour-processed goods prior to customer delivery. 

It links directly to outbound Delivery Challans (either **Manufacturing** sales dispatch `dcinv` or **Labour** outgoing dispatch `dcoutgoinginv`), capturing:
1. Dispatch and item context (DC No, DC Date, Customer, DC Qty, Item Code, Item Name).
2. Sample inspection parameters (Description, Nominal Dimension, Lower Tolerance, Upper Tolerance).
3. Random measurement readings across up to 10 component samples (`comp 1` through `comp 10`).
4. Quality inspector attribution (`Inspected By` staff member) and inspection remarks.
5. Bidirectional template synchronization with `inspect_ref` for re-usable component measurement standards.

## 2. Visual Layout & Form Components
Matches screenshot `SCREENSHOTS/INSPECTION/MANUFACTURING_&_LABOUR/001_random_samples.png` and bytecode `vbdec/1792468542.txt`, `vbdec/1184265284.txt`, `vbdec/2006140760.txt`:

### Top-Left: Select DC Type & Data (`Frame2`)
- **DC Type** (`cmbDCtype`): Dropdown with options:
  - `Manufacturing` (Default, pulls from `dcinv` / `dcinvsub`)
  - `Labour` (Pulls from `dcoutgoinginv` / `dcoutgoingsubinv`)
- **DC NO.** (`cmbDcNo`): Searchable/selectable dropdown of dispatch DC numbers.
- **DC DATE** (`txtDCdate`): Display of delivery challan date (readonly).
- **CUSTOMER** (`txtCust`): Display of customer name (readonly).
- **DC Qty.** (`txtDCqty`): Quantity dispatched in selected DC for the chosen item (readonly).
- **ITEM CODE / PART NO.** (`cmbComp`): Dropdown of items included in the chosen delivery challan.
- **ITEM NAME / COMPONENT** (`txtPartNo`): Display of item name / particulars (readonly).

### Top-Right: Inspection Auto Running No (`Frame3`)
- **INSPECTION REPORT NO.** (`txtInsNo`): Sequential inspection report number (defaults to max + 1).
- **DATE** (`dtpInsDate`): Inspection date picker (defaults to current date).

### Middle: Multi-Sample Measurement Grid (`msflex`)
15-column data table:
- Col 0: `SlNo` (Sequential row counter: 1, 2, 3...)
- Col 1: `Desc.` (Inspection parameter description, e.g. "Outer Diameter", "Thickness", "Thread Pitch")
- Col 2: `Dimens` (Nominal / Specified dimension, e.g. "25.00")
- Col 3: `Lo Tol` (Lower tolerance limit, e.g. "-0.05")
- Col 4: `Hi Tol` (Upper tolerance limit, e.g. "+0.05")
- Col 5 to 14: `comp 1`, `comp 2`, `comp 3`, `comp 4`, `comp 5`, `comp 6`, `comp 7`, `comp 8`, `comp 9`, `comp 10` (Actual measured dimensions across 10 random samples).

### Action Controls Beneath Grid:
- **INSPECTED BY** (`cmbInsBy`): Dropdown of quality inspection staff members (`staff` table).
- **Load Data** (`lblLoadInsCommon`): Button that pulls saved inspection parameter templates from `inspect_ref` for the selected `ItemId`.
- **Delete Last Row** (`cmdDelRow`): Button that deletes the last parameter row from the grid.
- **\* REMARKS** (`txtRem`): Text input for inspection observations and pass/fail notes.

### Bottom Toolbar (`Frame31`)
- `New`: Clears form, loads next inspection number, resets to today's date and default grid row.
- `Save`: Validates and commits inspection report to `inspection` table and updates `inspect_ref`.
- `Delete`: Deletes the current inspection report.
- Navigation (`<<|`, `<<`, `>>`, `|>>`): Moves across inspection records sequentially.
- `Printer`: Opens standard printable inspection certificate (`/api/print?type=inspection-random&id=...`).
- `Close`: Closes window.

## 3. Database Schema

### Table: `inspection`
```sql
CREATE TABLE IF NOT EXISTS inspection (
  id integer GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  factory_id integer NOT NULL REFERENCES factories(id),
  year_label text NOT NULL,
  ins_no text NOT NULL,
  ins_date date NOT NULL,
  dc_type text NOT NULL, -- 'Manufacturing' or 'Labour'
  dc_no text,
  dc_date date,
  cust_id integer,
  qty double precision NOT NULL DEFAULT 0,
  item_id integer,
  ins_by text,
  remarks text,
  ins_data text, -- Serialized tab-delimited/JSON measurement rows
  tot_rows integer NOT NULL DEFAULT 0,
  created_at timestamp with time zone DEFAULT CURRENT_TIMESTAMP
);
```

### Table: `inspect_ref`
```sql
CREATE TABLE IF NOT EXISTS inspect_ref (
  id integer GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  factory_id integer NOT NULL REFERENCES factories(id),
  year_label text NOT NULL,
  item_id integer NOT NULL,
  ins_ref_data text, -- Template parameter rows (Desc, Dimens, LoTol, HiTol)
  tot_rows integer NOT NULL DEFAULT 0,
  created_at timestamp with time zone DEFAULT CURRENT_TIMESTAMP
);
```
