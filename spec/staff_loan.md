# Specification: Human Resource - Staff Loan (`frmStaffLoan`)

## 1. Overview
The **Staff Loan** module (`frmStaffLoan`) manages employee loans and advances, tracking loan issuance reasons, issued amounts, recovery repayment schedules (months), issue dates, remaining balances, and deduction history recorded through payroll/salary deductions.

## 2. Legacy VB6 Bytecode Analysis & Controls
From bytecode analysis of `frmStaffLoan` (`vbdec/1338155519.txt`, `vbdec/451821613.txt`, `vbdec/490570257.txt`, `vbdec/1360626339.txt`, `vbdec/130358212.txt`, `vbdec/1020068266.txt`, `vbdec/1019461454.txt`, `vbdec/310895972.txt`):
- **Form Caption**: `STAFF LOAN`
- **Employee Selection**:
  - `chkEmpCurr`: Checkbox `"Current Employees Only"` (default checked = 1).
    - Checked: `Select * from staff where statusC=true order by staffName`
    - Unchecked: `Select * from staff order by staffName`
  - `lstStaff`: Listbox showing employee names.
- **Labels**:
  - `lblName`: Label displaying selected employee name.
  - `lblLoanBal`: Label displaying `"Loan Balance: <balance>"` (total outstanding balance for active loans).
  - `lblCorres`: Correspondence count link (`"Correspondences (0 / 0)"`).
- **Main Loan Grid (`msfMain`)**:
  - Headers:
    ` Loan No.  | Sl.No |            Description (Loan Iss. Reason)   |  Loan Amt.   |  No. of Months (to recover)  |    Date Of Issue (dd/mm/yyyy)|   Balance    `
  - Col 0: `Loan No.` (auto-assigned / loanid)
  - Col 1: `Sl.No` (row sequence: 1, 2, 3...)
  - Col 2: `Description (Loan Iss. Reason)` (text reason)
  - Col 3: `Loan Amt.` (issued amount, formatted with 2 decimal places)
  - Col 4: `No. of Months (to recover)` (integer duration)
  - Col 5: `Date Of Issue (dd/mm/yyyy)` (issue date, format `dd/mm/yyyy` or `yyyy-mm-dd`)
  - Col 6: `Balance` (remaining balance; for a new loan, `Balance = Loan Amt.`)
- **Recovery Details Checkbox & Grid (`chkDetails` & `msflex`)**:
  - `chkDetails`: Checkbox `"Recovery Details"`.
  - When checked, expands/shows recovery history grid (`msflex`):
    ` Loan No.   | Deducted Date         | Amt. Deducted        |    Deducted From   `
  - Populated from:
    - `Select saldate,loanamtded,LoanDedId from Salary where staffid=... and loanamtded>0`
    - `select * from StaffLoanDedTrack where LoanDedId=...`
- **Action Buttons**:
  - `cmdSave`: Button labeled `&Save` when selected employee has no loans, or `&Modify` when editing an employee with existing loans.
  - `cmdDelete`: Button labeled `&Delete`.
  - `cmdExit`: Button labeled `E&xit`.

## 3. Exact VB6 Validations & Messages
1. **No Employee Selected**:
   - `MsgBox "No Employee Name selected..... "`
2. **Empty Grid (Rows == 1 / No Rows)**:
   - `MsgBox "Please Enter the  details by clicking the grid heading....."`
3. **Empty Description (Col 2)**:
   - `MsgBox "Enter the Description for the SlNo. " & SlNo`
4. **Zero Loan Amount (Col 3)**:
   - `MsgBox "Enter the Loan Amount for the SlNo. " & SlNo`
5. **Zero Repayment Months (Col 4)**:
   - `MsgBox "Enter the No. of Months within which the loan amount has to be recovered  "`
6. **Invalid Date of Issue (Col 5)**:
   - `MsgBox "Enter the valid Date of Issue of Loan Amount (in dd/mm/yyyy format)..."`
7. **Save Confirmation**:
   - `MsgBox "Are You Sure To Save?", vbYesNo + vbQuestion` or `"Are You Sure To Modify?", vbYesNo + vbQuestion`
8. **Save Success**:
   - `MsgBox "Record succussfully Stored ."` (exact legacy spelling)
9. **Delete Confirmation**:
   - `MsgBox "This will Delete all the Loans containing 'Balance=Loan Amount(Issued)'\r\n\r\nAre You Sure To Delete?", vbYesNo + vbQuestion`
10. **Delete Operation**:
    - `delete from StaffLoan where staffid = $1 and loanamt = balance`
    - (Only untouched loans where no recovery deductions have been made are deleted!)
11. **Delete Success**:
    - `MsgBox "Record succussfully Deleted ."`

## 4. Database Schema
PostgreSQL tables in `smart-erp/db.js`:
```sql
CREATE TABLE IF NOT EXISTS staffloan (
  loanid integer GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  factory_id integer NOT NULL REFERENCES factories(id),
  year_label text NOT NULL,
  staffid integer NOT NULL,
  loanamt double precision NOT NULL DEFAULT 0,
  loandate date NOT NULL,
  repayperiod integer NOT NULL DEFAULT 0,
  repayamt double precision NOT NULL DEFAULT 0,
  balance double precision NOT NULL DEFAULT 0,
  reason text,
  closed boolean NOT NULL DEFAULT false,
  created_at timestamp with time zone DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE IF NOT EXISTS staffloandedtrack (
  id integer GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  factory_id integer NOT NULL REFERENCES factories(id),
  year_label text NOT NULL,
  loandedid integer NOT NULL,
  staffid integer NOT NULL,
  loanamtded double precision NOT NULL DEFAULT 0,
  saldate date NOT NULL,
  created_at timestamp with time zone DEFAULT CURRENT_TIMESTAMP
);
```

## 5. API Endpoints
- `GET /api/staff-loan/staff?current=true|false`:
  Returns active staff list (`staffid`, `staffname`) based on `statusc` flag.
- `GET /api/staff-loan?staffId=<id>`:
  Returns:
  - `staff`: Staff record (`staffid`, `staffname`)
  - `loans`: Array of loan rows for employee ordered by `loanid`
  - `recovery`: Array of deduction entries from `staffloandedtrack`
  - `totalBalance`: Sum of active balances
  - `mode`: `"save"` (if 0 loans) or `"modify"` (if >= 1 loans)
- `POST /api/staff-loan/save`:
  Validates rows, saves or updates `staffloan` records within a database transaction.
  Returns `{ message: "Record succussfully Stored .", success: true }`.
- `POST /api/staff-loan/delete`:
  Deletes loans where `staffid = $1 AND loanamt = balance`.
  Returns `{ message: "Record succussfully Deleted .", count: deletedCount }`.
