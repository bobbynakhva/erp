# Specification: Inspection COMMON (`frmInspectionIn`)

## 1. Overview
The **Inspection COMMON** module (`frmInspectionIn`) provides standardized final inspection reporting for manufactured components against customer specifications, supporting full 10-sample dimensional verification and automatic template synchronization with `inspect_ref`.

### Titlebar:
- Title: `FINAL INSPECTION REPORT - COMMON`
- Action Buttons: `Correspondences (0/0)`, `×` (Close)

### Identification & Customer Panel (Top Left):
- **Customer** (`cmbCustomer`): Dropdown listing customers from `customer` ordered by `custname`.
- **Part No / Item Code** (`cmbComp`): Dropdown of items from `item where hide = 0` ordered by `itemcode`.
- **Component Name** (`txtPartNo`): Auto-filled from `item.item_name` (readonly).
- **Inspection Qty** (`txtDCqty`): Numeric quantity inspected.

### Report Info Panel (Top Right):
- **Inspection No** (`txtInsNo`): Sequential inspection number.
- **Inspection Date** (`dtpInsDate`): Inspection Date.

### Inspector & Remarks Bar:
- **Inspected By** (`cmbInsBy`): Dropdown of inspectors from `inspection_in` and `staff`.
- **\* Remarks** (`txtRem`): Optional inspection remarks.
- Grid Row Actions: `+ Add Row`, `- Del Row`.

### Measurement Grid (`msflex`):
15 columns:
- Col 0: `SlNo`
- Col 1: `Desc.`
- Col 2: `Dimens`
- Col 3: `Lo Tol`
- Col 4: `Hi Tol`
- Cols 5 to 14: `comp 1` through `comp 10`

### Bottom Toolbar:
- `New`, `Save` / `Modify`, `Delete`
- Navigation: `|<<` (First), `<<` (Previous), `>>` (Next), `>>|` (Last)
- Search: Search input (`txtGO`) and `Find` button (`lblGO`).
- `Printer`: Opens printable certificate (`/api/print?type=inspection-common&id=...`).
- `Close`: Closes the window.

## 3. Database Schema
PostgreSQL table `inspection_in`:
```sql
CREATE TABLE IF NOT EXISTS inspection_in (
  id integer GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  factory_id integer NOT NULL REFERENCES factories(id),
  year_label text NOT NULL,
  ins_no text NOT NULL,
  ins_date date NOT NULL,
  cust_id integer,
  item_id integer,
  qty double precision NOT NULL DEFAULT 0,
  ins_by text,
  remarks text,
  ins_data text,
  tot_rows integer NOT NULL DEFAULT 0,
  created_at timestamp with time zone DEFAULT CURRENT_TIMESTAMP
);
```
