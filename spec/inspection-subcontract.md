# Specification: SubContract Inspection (`frmInspectionSC`)

## 1. Overview
The **SubContract Inspection** module (`frmInspectionSC`) provides quality assurance and verification for incoming components received from subcontractors / suppliers against Delivery Challans (`DcSubConIncoming`).

---

## 2. Visual Layout & Form Components
Matches `SCREENSHOTS/INSPECTION/001_subcontract.png` and bytecode `vbdec/1648574417.txt`, `vbdec/2037846039.txt`, `vbdec/1028768214.txt`, `vbdec/1427840836.txt`, `vbdec/1552819026.txt`, `vbdec/199893475.txt`, `vbdec/528081303.txt`:

### Titlebar:
- Title: `FINAL INSPECTION REPORT - SUBCONTRACT`
- Right: `Correspondences (0/0)` link button, `×` close button

### Selection Panel (Left):
- **DC Type** (`cmbDCtype`): Dropdown with `"SubContract"`.
- **DC NO.** (`cmbDcNo`): Dropdown listing Delivery Challans from `dcsubconincoming`.
- **DC DATE** (`txtDCdate`): Delivery Challan Date (readonly).
- **SUBCONTRACTOR** (`txtSupp`): SubContractor / Supplier name (readonly).
- **ITEM CODE / PART NO.** (`cmbComp`): Dropdown of items associated with the selected DC.
- **COMPONENT** (`txtPartNo`): Component / Item Name (readonly).
- **DC Qty.** (`txtDCqty`): Dispatched quantity from the DC line item (readonly).
- **REJECTION Qty.** (`txtRejQty`): Rejection quantity (validated to not exceed `DC Qty`).

### Inspection Running Number Panel (Right):
- **INSPECTION REPORT NO.** (`txtInsNo`): Sequential inspection number.
- **DATE** (`dtpInsDate`): Date of inspection report.

### Header Details Row:
- **INSPECTED BY** (`cmbInsBy`): Inspector dropdown populated from staff and prior records.
- **\* REMARKS** (`txtRem`): Optional inspection remarks.
- Grid actions: `+ Add Row`, `Delete Last Row`.

### Measurement Grid (`msflex`):
15 columns:
- Col 0: `SlNo`
- Col 1: `Desc.`
- Col 2: `Dimens`
- Col 3: `Lo Tol`
- Col 4: `Hi Tol`
- Cols 5 to 14: `comp 1` through `comp 10`

### Bottom Toolbar:
- `New`, `Save` / `Modify`, `Delete`
- Navigation: `|<<`, `<<`, `>>`, `>>|`
- Search: Search by Inspection Report Number.
- `Printer`: Opens printable certificate (`/api/print?type=inspection-sc&id=...`).
- `Close`: Closes window.

## 3. Database Schema
PostgreSQL table `inspection_sc`:
```sql
CREATE TABLE IF NOT EXISTS inspection_sc (
  id integer GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  factory_id integer NOT NULL REFERENCES factories(id),
  year_label text NOT NULL,
  dctype text DEFAULT 'SubContract',
  ins_no text NOT NULL,
  ins_date date NOT NULL,
  supp_id integer,
  dc_no text,
  dc_date date,
  qty double precision NOT NULL DEFAULT 0,
  rej_qty double precision NOT NULL DEFAULT 0,
  item_id integer,
  ins_by text,
  remarks text,
  ins_data text,
  tot_rows integer NOT NULL DEFAULT 0,
  created_at timestamp with time zone DEFAULT CURRENT_TIMESTAMP
);
```

## 4. Exact VB6 Validations & Dialog Messages

   - `"Enter the Inspection Number "` *(note trailing space)*

   - `"Please Select a DC Number....."`

   - `"Please Select a Item Code/Part No......"`

   - `"Enter the Person who has made the Inspection"`

   - `"You must fill 'Dimension' column !!!"`
6. **Rejection Quantity Exceeds DC Quantity:**
   - `"Rejected Qty Should not exceed "` + `DC Qty`
7. **Duplicate Inspection Report Number:**
   - `" A Record with same Inspection No. already exists ! "`
8. **Save Prompt & Confirmation:**
   - Prompt: `"Store the data ?"`
   - Success: `"Record Stored successfully ."`

   - Prompt: `"Are You Sure To Delete The Records ?"`
   - Success: `"Records Deleted"`

    - `"You should save the Record First in order to take print..."`
