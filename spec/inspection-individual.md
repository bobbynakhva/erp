# Specification: Final Inspection Report - Individual Samples (`frmInspectionInde`)

## 1. Overview
The **Final Inspection Report (Individual Samples)** module (`frmInspectionInde`) provides precision quality assurance tracking for high-criticality components where individual serial numbers and heat/batch numbers must be verified sequentially.

Unlike the Random Samples module (which samples a generic batch of 10), the Individual Samples module dynamically binds columns 5 through 14 of the measurement grid to specific serial numbers starting from `txtSno` (Serial Number `Sno` through `Sno + 9`).

---

## 2. Visual Layout & Form Components
Matches screenshot `SCREENSHOTS/INSPECTION/MANUFACTURING_&_LABOUR/002_individual_samples.png` and bytecode `vbdec/1186046216.txt`, `vbdec/1234614067.txt`, `vbdec/1111791852.txt`, `vbdec/1655606394.txt`, `vbdec/1895063145.txt`, `vbdec/219744082.txt`:

### Form Header & Title:
- Title Bar: `FINAL INSPECTION REPORT - INDIVIDUAL SAMPLES`

### Metadata Panel:
- **Serial Number** (`txtSno`): Starting serial number of the inspection batch (e.g. `1`, `11`, `101`).
- **Heat / Batch No** (`txtBatchNo`): Raw material or foundry melt batch identifier.
- **Inspection Sheet No** (`txtSheetno`): Sequential inspection certificate / sheet number.
- **Date** (`dtpSheetDate`): Date of inspection report.
- **Vendor Code** (`txtvendcode`): Optional customer/vendor code.
- **DC NO.** (`txtDCNo`): Outgoing Delivery Challan number.
- **DC DATE** (`dtpDCDate`): Date of Delivery Challan.
- **CUSTOMER** (`cmbCust`): Customer dropdown.
- **DC Qty.** (`txtDCqty`): Dispatched quantity.
- **ITEM CODE / PART NO.** (`cmbComp`): Component item code dropdown.
- **COMPONENT** (`txtPartNo`): Component item name (readonly display).
- **Description** (`txtDesc`): Part/process description.
- **P.O. NO.** (`txtPono`): Purchase Order / Work Order reference.
- **INSPECTED BY** (`cmbInsBy`): Quality inspector dropdown.
- **Lock Columns** (`chkLockCOLS`): Checkbox to lock/unlock column headers.
- **\* REMARKS** (`txtRem`): Remarks and inspection notes.

### Grid & Linking Controls:
- **Load Existing Data** (`lblLoadInsCommon`): Checks `Customer` and `Item Code`, allows importing standard parameters from prior reports or `inspect_ref`.
- **Measurement Grid (`msflex`)**: 15 columns:
  - Col 0: `SlNo` (1, 2, 3...)
  - Col 1: `Desc.` (Inspection parameter description)
  - Col 2: `Dimens` (Nominal dimension)
  - Col 3: `Lo Tol` (Lower tolerance limit)
  - Col 4: `Hi Tol` (Upper tolerance limit)
  - Col 5 to 14: Individual serial readings dynamically labeled from `Sno` to `Sno + 9`.

### Bottom Toolbar:
- `New`: Clears form, loads next sheet number, resets grid.
- `Save` / `Modify`: Validates and saves inspection report and updates `inspect_ref`.
- `Delete`: Deletes the inspection report with confirmation.
- Navigation (`|<<`, `<<`, `>>`, `>>|`): First, Previous, Next, Last.
- Search: Search by Sheet / Inspection Number.
- `Printer`: Opens printable certificate (`/api/print?type=inspection-inde&id=...`).
- `Close`: Closes window.

## 3. Database Schema
Table `inspection_inde` in PostgreSQL:
```sql
CREATE TABLE IF NOT EXISTS inspection_inde (
  id integer GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  factory_id integer NOT NULL REFERENCES factories(id),
  year_label text NOT NULL,
  sheet_no text NOT NULL,
  ins_no text,
  batch_no text,
  sheet_date date NOT NULL,
  vc_no text,
  dc_no text,
  dc_date date,
  cust_id integer,
  qty double precision NOT NULL DEFAULT 0,
  item_id integer,
  description text,
  po_no text,
  ins_by text,
  remarks text,
  ins_data text,
  tot_rows integer NOT NULL DEFAULT 0,
  created_at timestamp with time zone DEFAULT CURRENT_TIMESTAMP
);
```
