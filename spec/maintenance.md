# Specification: Maintenance Modules (`frmMaintain` & `frmMaintainPro`)

## 1. Overview
The Maintenance subsystem manages preventive maintenance schedules and execution tracking for factory machinery:
1. **Maintenance Schedule (`frmMaintain`)**: Defines recurring maintenance tasks, schedules, and frequencies for each machine.
2. **Maintenance Process (`frmMaintainPro`)**: Logs daily execution status (`Y`/`N`) for scheduled preventive maintenance across all machines.

## 2. Frequencies & Permitted Day/Month Values
The system defines 6 standard maintenance frequencies (`maintenance` table):
- **M1 - Weekly**: Scheduled Day between 1 and 7 (`1-Sunday 7-Saturday`)
- **M2 - Fortnightly**: Scheduled Day between 1 and 13
- **M3 - Monthly**: Scheduled Day between 1 and 28
- **M4 - Quarterly**: Scheduled Month between 1 and 3 (`1-January 3-March`)
- **M5 - Bi-Annual**: Scheduled Month between 1 and 6 (`1-January 6-June`)
- **M6 - Annual**: Scheduled Month between 1 and 12 (`1-January 12-December`)

## 3. Database Schema
PostgreSQL tables:
```sql
CREATE TABLE IF NOT EXISTS maintenance (
  factory_id integer NOT NULL REFERENCES factories(id),
  year_label text NOT NULL,
  mainid integer NOT NULL,
  mainname text NOT NULL,
  PRIMARY KEY (factory_id, year_label, mainid)
);

CREATE TABLE IF NOT EXISTS maintainsch (
  id integer GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  factory_id integer NOT NULL REFERENCES factories(id),
  year_label text NOT NULL,
  mainid integer NOT NULL,
  machid integer NOT NULL,
  descr text,
  schday integer NOT NULL DEFAULT 1,
  created_at timestamp with time zone DEFAULT CURRENT_TIMESTAMP,
  CONSTRAINT uq_maintainsch_factory_main_mach UNIQUE (factory_id, year_label, mainid, machid)
);

CREATE TABLE IF NOT EXISTS maintaindata (
  id integer GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  factory_id integer NOT NULL REFERENCES factories(id),
  year_label text NOT NULL,
  mainid integer NOT NULL,
  machid integer NOT NULL,
  maindate date NOT NULL,
  statusc boolean NOT NULL DEFAULT false,
  descr text,
  created_at timestamp with time zone DEFAULT CURRENT_TIMESTAMP,
  CONSTRAINT uq_maintaindata_factory_record UNIQUE (factory_id, year_label, mainid, machid, maindate)
);
```

## 4. Exact VB6 Validations & Messages
1. **No Machines Available**:
   - `MsgBox "No Machine Exists !"` or `"No Machine exists!!!"`
2. **Missing Maintenance Type Selection**:
   - `MsgBox "Select a Maintenance Type ..."`
3. **Out-of-range Scheduled Day/Month**:
   - Weekly: `"Scheduled Day must be between 1 and 7 (1-Sunday 7-Saturday)"`
   - Fortnightly: `"Scheduled Day must be between 1 and 13"`
   - Monthly: `"Scheduled Day must be between 1 and 28"`
   - Quarterly: `"Scheduled Month must be between 1 and 3 (1-January 3-March)"`
   - Bi-Annual: `"Scheduled Month must be between 1 and 6 (1-January 6-June)"`
   - Annual: `"Scheduled Month must be between 1 and 12 (1-January 12-December)"`
4. **Save Success Message**:
   - `MsgBox "Data stored successfully ."` (exact legacy punctuation)

## 5. API Endpoints
- `GET /api/maintenance/schedule?mainId=<id>`:
  Returns maintenance types list and machine schedule list for selected frequency.
- `POST /api/maintenance/schedule/save`:
  Validates and saves schedule entries. Returns `{ success: true, message: "Data stored successfully ." }`.
- `GET /api/maintenance/process?date=<YYYY-MM-DD>`:
  Returns all machines and their M1..M6 maintenance tasks and execution status for the given date.
- `POST /api/maintenance/process/save`:
  Saves execution updates (`statusc = true/false`). Returns `{ success: true, message: "Data stored successfully ." }`.
