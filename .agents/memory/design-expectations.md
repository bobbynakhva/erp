---
name: Premium design expectations
description: Visual quality expectations for ERP modernization and concept previews.
---

The user wants premium, contemporary design. A recolored legacy desktop window with a photographic wallpaper does not satisfy that requirement.

**Why:** The user rejected that approach and repeated, “I want premium design.”

**How to apply:** Preserve business fields, their sequence, and form columns, but make substantial improvements to presentation, hierarchy, typography, controls, and the surrounding composition. Do not impose exact legacy container dimensions as an additional constraint.

The user approved the Premium Tamba concept with an integrated photographic/editorial region and a separate credential region, then asked to apply that direction to the ERP.

**Why:** The user selected “Use this direction” after seeing the redesigned sample.

**How to apply:** Keep that approved visual identity as the reference for subsequent ERP interface work rather than returning to a recolored desktop-window treatment.
